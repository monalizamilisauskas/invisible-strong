# invisible-strong

Loja oficial Invisible Strong – [www.invisiblestrong.com](https://www.invisiblestrong.com)

Tema Shopify (Horizon) conectado via integração GitHub da Shopify.

## Estrutura
- `layout/` – layout base (`theme.liquid`)
- `templates/` – modelos de páginas (JSON)
- `sections/` e `blocks/` – seções e blocos editáveis no editor de temas
- `snippets/` – trechos Liquid reutilizáveis
- `assets/` – CSS, JS e imagens
- `config/` – configurações do tema (`settings_data.json` guarda as personalizações)
- `locales/` – traduções

> Alterações feitas no editor da Shopify são enviadas automaticamente para a branch `main`.
